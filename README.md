# منصة ثانوية الفراجية للبنين — Android

هذا المشروع يعتمد على `www/index.html` باعتباره النسخة الأصلية للمنصة.

## ما تمت إضافته

- تغليف المنصة كتطبيق Android باستخدام Capacitor.
- طبقة Queue محلية دائمة لتغييرات Firebase التي تحدث أثناء انقطاع الإنترنت.
- مزامنة تلقائية عند توفر الشبكة بواسطة Android WorkManager.
- عند إغلاق التطبيق، تبقى التغييرات المعلقة محفوظة محليًا حتى يستطيع Android تشغيل مهمة المزامنة.
- بناء APK وAAB عبر GitHub Actions.

## ملاحظة مهمة

لا يتم حذف أو إعادة تصميم وظائف المنصة. التعديل الوحيد داخل `index.html` هو إضافة استدعاء طبقة المزامنة الأصلية عندما تفشل كتابة Firebase أو لا يكون الاتصال متاحًا.

## البناء في GitHub

1. أنشئ مستودعًا جديدًا وارفع جميع ملفات المشروع.
2. افتح تبويب **Actions**.
3. شغّل **Build Android APK and AAB**.
4. بعد نجاح البناء ستجد `alfarajia-apk` و`alfarajia-aab` ضمن Artifacts.

## Firebase

المشروع يستخدم إعداد Firebase الموجود أصلًا داخل النسخة الأصلية للمنصة. لا توجد خدمة جديدة أو قاعدة بيانات جديدة مفروضة على المشروع.
